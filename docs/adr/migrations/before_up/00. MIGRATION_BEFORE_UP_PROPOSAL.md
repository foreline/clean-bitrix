# Migration Before Up Proposal

This document outlines the proposal task for implementing the "Migration Before Up" and "Migration Before Down" features. These features are designed to allow users to perform necessary actions before executing the main migration steps, ensuring a smoother and more controlled migration process.

## Scenario
A developer refactored the codebase, which led to changes in namespace structures. As a result the database tables also need to be renamed to reflect the new namespace. If we generate and run the migration as is, only new tables will be created, and the old tables will remain unchanged. This can lead to data inconsistency and confusion.
So the developer adds a "Migration Before Up" step to rename the existing tables before the EntityTable::checkTable() method is called. This ensures that the data is preserved and the new structure is correctly implemented.
